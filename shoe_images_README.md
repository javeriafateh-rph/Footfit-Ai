# shoe_images/

Drop a real photo of a shoe here and the app will automatically use it for
"See it on you" — no shoe-photo upload needed for that shoe anymore. Only
the person's own photo is needed.

## How it works

The app looks for a file named exactly `<shoe-slug>.jpg` (or `.jpeg`/`.png`)
in this folder, where `<shoe-slug>` is the shoe's name, lowercased, with
spaces and punctuation turned into dashes. If the file exists, it's used
automatically. If it doesn't, that shoe falls back to asking for a manual
shoe-photo upload — nothing breaks either way.

## For your hackathon demo specifically

You don't need all 26 filled in — you only need photos for the 1-3 shoes
you'll actually show trying on in your video. Save just those, upload them
here (same drag-and-drop process as any other file on GitHub — this is a
folder, so use "Add file" → "Upload files" and select the images), and
those specific shoes will skip the shoe-photo upload step automatically.
Every other shoe keeps working exactly as before (manual shoe-photo upload)
until you add more images later.

## Where to get a photo

A screenshot of the shoe from the brand's own product page (the same site
linked in "View Product") works fine for a demo. Keep it to a plain product
shot if possible — busy backgrounds can confuse the try-on result.
